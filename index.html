Manager Library

A complete library management system: catalog, members, loans, and reports.

React + Laravel + PostgreSQL 16

Features

Book Catalog

Search, filter by category, manage covers. Logical delete preserves history.

Members

Register members with unique document numbers. No deletion — members are data.

Loans

1-3 books per loan, 14-day term, max 3 active per member. Return by line item.

Overdue Tracking

Automatic overdue detection. Members with overdue loans cannot borrow more.

Reports

Most borrowed books by date range. Frozen values preserve historical accuracy.

Roles

Admin manages everything. Librarian registers loans and returns.

Roles

Admin

  • Manage book catalog
  • Create librarians
  • View reports
  • Manage members

Librarian

  • Register loans
  • Process returns
  • View overdue loans
  • Search catalog and members
